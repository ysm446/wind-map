# Changelog

作成日時: 2026-06-12 23:20
更新日時: 2026-06-13 05:15

## 未リリース

- 2026-06-13 05:15: 起動時はメニューの全セクションを閉じた状態にした(パーティクルも
  既定で閉じる)。FPS 表示をメニュー内から画面右上の固定位置へ移し、「FPS を表示する」
  チェックボックス(表示設定内、既定ON)で切り替え可能にした。設定は settings.json に永続化。

- 2026-06-13 05:05: 右下の日付・時刻表示の各数字を固定幅セル(1ch)に入れ、表示する
  数字やアニメーションで桁位置がずれないようにした。2行は flex 縦並びの右寄せに変更。

- 2026-06-13 04:50: 起動時、設定タイムゾーンに対応する経度(オフセット×15°)を
  正面に向けるようにした。例: UTC+9 → 東経135°(日本付近)が中央に来る。

- 2026-06-13 04:40: 起動時に最新データを自動取得する設定を追加(「データ取得」内の
  チェックボックス、既定ON)。まずキャッシュ/サンプルを即表示し、その後バックグラウンドで
  最新ランの解析(f000、現在時刻に最も近い実データ)を取得して差し替える。取得中も
  操作はブロックせず、失敗時はキャッシュ表示のまま静かに継続。設定は settings.json に永続化。

- 2026-06-13 04:25: 時刻表示のタイムゾーン設定を追加(「表示設定」内、UTC-12〜+14、
  既定 UTC+9)。右下の日付表示・データソースラベル・保存データ一覧の時刻に適用し、
  末尾ラベルを「UTC」→「UTC+9」のように表示。過去日時・区間の開始/終了の入力欄も
  選択中タイムゾーンの壁時計時刻として解釈し、取得時に内部で UTC へ変換する。
  設定は settings.json に永続化。

- 2026-06-13 04:05: アニメーション再生にフレーム補間を追加(チェックボックスで
  切り替え、既定ON)。再生位置を連続値にし、隣接2コマの u/v を時間補間して風場を
  滑らかに変化させる(3時間刻みでも流れが途切れない)。GPUパーティクルとオーバーレイ
  はテクスチャをその場更新して反映。CPUフォールバック環境では補間不可のため無効化。

- 2026-06-13 03:45: 左パネルを各セクション開閉式に再構成。「パーティクル」
  「風速オーバーレイ」「表示設定」「データ取得」「保存データ / アニメーション」の
  折りたたみ(`<details>`)にまとめ、既定では「パーティクル」のみ開く。縦に長くなった
  ときのためにパネル自体も縦スクロール可能にした(`max-height` + `overflow-y`)。

- 2026-06-13 03:30: 風データの保存と時間アニメーションを追加。取得した風を
  「コレクション」としてファイル型DB (userData/wind-db) に永続保存し、一覧から
  選んで連続再生できる。区間管理UI(名前付け・削除、出自=予報/過去アーカイブの
  選択、開始/終了・時間刻みの指定)と、再生UI(再生/一時停止・スクラブ・速度
  =秒/コマ・開始/終了位置・ループ)を「保存データ / アニメーション」セクションに
  追加。各フレームは u/v を Float32 バイナリで保存(1°格子で約0.5MB/枚)。
  `npm run test:db` で保存・読み出しを検証可能。

- 2026-06-13 03:12: 右下に風データの有効日時を大きな細字フォントで表示。
  日付 (64px) + 時刻 UTC (24px) の 2 段、Bahnschrift Light (DIN 系、Windows 標準)。
  合成風場など日時のないデータでは非表示。

- 2026-06-13 03:08: select のドロップダウンが OS のライトテーマで白く表示される
  問題を修正。`html` への `color-scheme: dark` 宣言と option の暗色指定で対応。

- 2026-06-13 02:57: パーティクル配色プリセットに「アース」を追加。
  暗い青緑の海に強風帯が黄〜金色、最強部が赤で浮かぶ earth.nullschool 風の配色。

- 2026-06-13 02:50: 「表示設定」セクション(折りたたみ式)を追加。
  海岸線・国境線(色 + 不透明度)、海・陸・経緯線・大気光・背景・星の色を
  カラーピッカーで変更でき、「既定に戻す」ボタンで初期値に復帰。
  パーティクル配色プリセット(標準 / Viridis / Turbo)もここで選択する。
  すべて settings.json に保存される。

- 2026-06-13 02:35: 海岸線・国境線の合成を加算合成から通常のアルファ合成に戻した。
  風速オーバーレイなど明るい下地の上で線が白飛びするため。

- 2026-06-13 02:15: パーティクルの明度スライダーを追加(0.1〜2.0、既定 1.0)。
  GPU は軌跡レイヤーの合成時に乗算、CPU フォールバックは頂点色に乗算する。

- 2026-06-13 02:00: 風速カラーオーバーレイを追加。地表を風速に応じた色で塗る
  (チェックボックスで ON/OFF、濃度スライダーと凡例付き)。
  風場テクスチャをシェーダーで直接サンプリングするため、データ差し替えも即時反映。

- 2026-06-13 01:51: Electron のデフォルトメニューを非表示にし、起動時のコンテンツ領域を 1600x900 に変更。
- 2026-06-13 01:20: 速度スライダーの上限を 3.0 から 1.0 に変更。
  1.0 超では移流が 1 フレームで格子を飛び越えて破綻気味になるため。

- 2026-06-13 01:15: 軌跡の長さの上限を 64 から 256 に拡張
  (蓄積バッファの減衰率の上限も 0.985 → 0.995 に引き上げ)。
  CPU フォールバック描画では負荷のため従来どおり 64 で頭打ち。

- 2026-06-13 01:10: 国境線(Natural Earth admin-0)を追加。海岸線と同じ
  ベクターライン + LOD 方式(110m/50m/10m、10m は遅延ロード)で、
  海岸線より控えめな明るさで表示する。

- 2026-06-13 00:57: 海岸線ラインの合成を通常のアルファ合成から加算合成に変更。
  発光風になり、粒子のグローと馴染むようにした。

- 2026-06-13 00:55: UI 設定(粒子数・速度・軌跡の長さ・予報時刻)をアプリ直下の
  `data/settings.json` に自動保存し、起動時に復元するようにした(変更の 500ms 後に保存)。

- 2026-06-13 00:50: 海岸線をベクターライン化し、カメラ距離に応じた LOD
  (110m / 50m / 10m) を追加。ズームしても輪郭が常にシャープになった。
  10m データは初回ズーム時に遅延ロード。陸地の塗りも 50m データ + 4096px に更新。

- 2026-06-13 00:35: 速度スライダーの既定値を 1.0 から 0.1 に変更(範囲も 0.1〜3.0 に拡大)。
  GPU 化で粒子の動きが見やすくなった分、既定の移流速度が速すぎたため。

- 2026-06-13 00:30: 起動やカメラ操作の数秒後に軌跡の明度が急に上がる問題を修正。
  カメラ移動判定に許容誤差を入れ(ダンピングのサブピクセル移動を誤検知しない)、
  減衰率の切り替えを瞬時ではなく滑らかな遷移にした。

- 2026-06-13 00:20: GPU パーティクルが時間とともに白っぽくなる問題を修正。
  蓄積バッファへの点描を加算合成からアルファ合成に変更
  (加算だと同じ画素に毎フレーム光が足され続けて飽和するため)。

- 2026-06-13 00:15: 風パーティクルを GPU 化。粒子数を 16,384〜1,048,576 から
  選べるようにした(既定 262,144)。軌跡は蓄積バッファ方式になり、
  「軌跡の長さ」スライダーは軌跡の残り具合を調整する。
  GPU 非対応環境では従来の CPU 描画(6000 粒子)に自動フォールバック。

- 2026-06-13 00:05: P2a 過去データ取得。「過去日時 (UTC)」を指定して
  2021-01-01 以降の任意の時点の風を表示できるようにした(AWS の GFS アーカイブを使用、
  認証不要)。idx + HTTP Range リクエストで必要な 2 レコードのみダウンロードする。

- 2026-06-12 23:49: パーティクルが寿命の終わりに徐々にフェードアウトするようにした
  (約24フレーム)。出現時も短くフェードインし、急に現れて急に消える感じを解消。
- 2026-06-12 23:45: P1 実データ取得。「最新データを取得」ボタンで NOMADS から
  最新の GFS 地上風(1.0°格子)をダウンロードして表示できるようにした。
  予報時刻(+0〜+120h)をスライダーで選択可能。取得結果はキャッシュされ、
  次回起動時はキャッシュ → 同梱サンプルの順で読み込む。
  GRIB2 の展開は純 TypeScript デコーダで行う(外部ツール不要)。
- 2026-06-12 23:32: 軌跡の長さをスライダーで調整できるようにした(4〜64 点、既定 32)。
  従来はコード内の定数(16 点)で固定だった。

## 0.1.0 - 2026-06-12 23:20

- `start.bat` を追加。ダブルクリックで依存導入・ビルド・起動まで自動で行う。
  (cmd は UTF-8 バッチを文字化けさせるため、バッチ内は ASCII のみで記述)
- P0 プロトタイプを実装。
  - Electron + Three.js による 3D 地球儀と風の流線アニメーション。
  - GFS の地表風データ(同梱サンプル、2014-01-31 00:00 UTC)を表示。
  - マウスで回転・ズーム。粒子数と速度をスライダーで調整可能。
  - データが読めない場合は合成風場で表示を継続。
