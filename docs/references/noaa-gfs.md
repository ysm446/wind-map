# NOAA GFS とは

作成日時: 2026-06-13 05:50
更新日時: 2026-06-13 05:55

このプロジェクトが風データの取得元として使っている **NOAA GFS** の概要メモ。

## 概要

**GFS(Global Forecast System、全球予報システム)** は、アメリカ海洋大気庁
**NOAA** の国立気象局 **NWS** 配下の **NCEP**(環境予測センター)が運用する、
全地球を対象とした数値天気予報モデルです。気温・風・気圧・湿度・降水など多数の
気象要素を、全球の格子上で予報します。世界中で広く使われる代表的な無料の
気象予報データで、`earth.nullschool.net` も同じ GFS を主データに使っています。

- 運用: NOAA / NWS / NCEP
- 種別: 数値天気予報(NWP)モデルによる全球予報
- 費用: 無料・認証不要で入手可能(パブリックデータ)

## 観測データの国際協力

GFS という予報モデルを走らせているのは米国(NOAA / NCEP)ですが、計算に必要な
初期値(現在の大気の状態)は、**世界中の国々が観測したデータ**を取り込んで作られます
(この取り込み処理を「データ同化」と呼ぶ)。つまり「米国が公開している GFS」は、
世界中の観測の協力の上に成り立っています。

観測データの主な出どころ:

- **地上観測** — 各国の気象官署・自動観測所
- **高層観測(ラジオゾンデ)** — 世界中で毎日上げられる気象観測気球
- **海上** — 船舶・ブイ(各国・国際プログラム)
- **航空機** — 運航中の航空機からの気象データ(AMDAR など)
- **気象衛星** — 米 NOAA に加え、欧州 EUMETSAT、日本の気象庁(ひまわり)、
  中国(風雲)、インド、ロシアなど各国の衛星

これらを取りまとめているのが国連機関の **WMO(世界気象機関)** です。

- **WIGOS / 全球観測システム(GOS)** — 観測網の枠組み
- **WIS(かつての GTS)** — 観測データを国際的にやり取りする通信網
- **データ交換方針** — WMO 決議40(1995)、および統合データ方針(2021 の決議1)により、
  基本的な気象データは各国間で自由・無償で交換することが取り決められている

各国も同様の観測データを使い、独自の全球モデル(欧州 ECMWF、日本 JMA-GSM など)を
運用しています。

## ラン(初期時刻)と更新頻度

- 1 日 **4 回**、協定世界時(UTC)の **00 / 06 / 12 / 18Z** に実行されます。
  この各実行を「ラン(run)」または「サイクル」と呼びます。
- 予報は初期時刻からの経過時間「予報時刻(forecast hour, fHHH)」で表されます。
  - `f000` はラン時刻そのもの(解析に近い値)。
  - そこから先の時刻の予報が `f003`, `f006`, … と続きます。
- 予報期間は概ね **16 日(384 時間)先**まで。前半は細かい刻み、後半は粗い刻みに
  なります(プロダクトにより異なる)。
- 公開はラン時刻から **数時間(目安 5 時間程度)遅れて**順次そろいます。
  そのため「最新」を取得しても、基準となるランは数時間前のものになります。

## 解像度とプロダクト

GFS は複数の水平解像度で配信されます(`pgrb2` ファイル群)。

| プロダクト | 水平解像度 | 用途の目安 |
|---|---|---|
| `pgrb2.0p25` | 0.25°(約 25km) | 最も高解像度。前半は 1 時間刻みが利用可能 |
| `pgrb2.0p50` | 0.5° | 中間 |
| `pgrb2.1p00` | 1.0°(約 100km) | 軽量。3 時間刻み |

データ形式は気象分野の標準である **GRIB2**(WMO FM 92)。変数・高度・予報時刻ごとの
「メッセージ」を連結したバイナリで、各メッセージは圧縮(単純/複合パッキング等)
されています。

> GFS は 2021-03-22 に **GFSv16** へ更新され、配信レイアウトの一部が変わりました
> (アーカイブの `atmos/` サブディレクトリ等)。

## 入手経路

- **NOMADS**(NOAA Operational Model Archive and Distribution System)
  - 最新ランの配信元。GRIB filter(`filter_gfs_*.pl`)で変数・高度・領域を絞って
    小さな GRIB2 を取得できる。
  - 注意: OpenDAP(DODS)アクセスは **2025 年に廃止**(SCN 25-81)。GRIB filter を使う。
- **クラウドのオープンデータ**
  - AWS Open Data(`noaa-gfs-bdp-pds` バケット)に過去ランがアーカイブされている
    (おおむね 2021-01-01〜)。`.idx` ファイルでレコードのバイト位置を調べ、
    HTTP Range で必要分だけ取得できる。
  - 同様のミラーは Google Cloud / Azure 等にもある。

## このプロジェクトでの利用

- 予報(最新): NOMADS の GRIB filter から **地上 10m 風(UGRD/VGRD)** を取得
  (`src/main/nomads.ts`)。
- 過去: AWS アーカイブから同じ地上 10m 風を `.idx` + HTTP Range で取得
  (`src/main/archive.ts`)。
- GRIB2 は外部バイナリを使わず純 TypeScript デコーダで展開(`src/main/grib2.ts`)。
- 現状は **1.0° 格子・3 時間刻み**を使用。0.25°(1 時間刻み)対応は今後の課題
  (`docs/plan/plan.md` 参照)。
