# プロジェクトの目的

作成日時: 2026-06-12 22:44
更新日時: 2026-06-12 22:44

## 目的

earth.nullschool.net のような「地球上の風の流れを視覚化する 3D マップ」を、
スタンドアローンのデスクトップアプリ(Electron)として作成する。

参考: https://earth.nullschool.net/#current/wind/surface/level/orthographic

## 完成形のイメージ

- 3D の地球儀をマウスで回転・ズームできる。
- 地表の風がパーティクルの流線として地球儀上をアニメーションする。
- 風速に応じてパーティクルの色が変わる。
- 表示する日時を選べる。現在の予報データに加えて、過去のデータにも遡れる。
- ネットワークから気象データを取得し、ローカルにキャッシュする。
- 単体で配布・起動できるスタンドアローンアプリである。

## 重視する価値

1. **見た目の質** — nullschool のような滑らかで美しい流線表現を目指す。
2. **データの本物らしさ** — 合成データではなく、実際の気象データ(GFS / ERA5)を使う。
3. **スタンドアローン性** — サーバーを別途立てずに、アプリ単体で動作する。
4. **過去への遡及** — 再解析データ(ERA5)により過去の風も表示できるようにする。

## 主要な技術選定(決定済み)

| 項目 | 選定 | 理由 |
|---|---|---|
| アプリ基盤 | Electron | Node.js でデータ取得・変換・キャッシュが自由にでき、外部バイナリも同梱できる |
| 3D 描画 | Three.js (WebGL) | 地球儀とパーティクル表現の自由度が最も高い |
| 言語 | TypeScript | 型安全と保守性 |
| 予報データ | NOAA GFS (NOMADS) | 無料・認証不要。nullschool と同じソース |
| 過去データ | ECMWF ERA5 (Copernicus CDS) | 1940 年まで遡れる再解析データ。無料登録で利用可 |
